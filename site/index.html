Your email, on your own disk.

Bmail is a free, open-source Windows app that keeps a local, read-only backup of your mailboxes as standard .eml files. You can browse, search and export them, and Bmail can check for new mail on a schedule.

Features

A complete copy that stays yours

Bmail only reads from your mail server. It never deletes, moves or flags messages, and local backups remain even if mail is later removed from the server.

Read-only and private

Mailbox credentials are encrypted with Windows. Your mail stays on your computer, and no hosted service is involved.

Standard .eml files

Messages and attachments are saved in a portable format that other mail apps can open. You can export any folder as a ZIP archive.

Browse and search

A built-in reader with sortable columns and safely isolated HTML. Press Ctrl+K to search by sender, folder, date range or backup status.

Scheduled and incremental

Run backups on a schedule. New-mail checks fetch only what's missing, and backups can be paused, resumed or stopped at any time.

Optional cloud copies

Copy verified backups to Google Drive, Dropbox or your iCloud Drive folder. This is off until you turn it on.

Coverage you can check

Statistics compare your local copy with the full mailbox, so you can see what has been saved and what hasn't.

How it works

Up and running in a few minutes

For most providers you'll need an app password, which you can create in your mail account's security settings.

  1. Install

    Download the setup file from the latest release and install it for your Windows user. The backup runtime is included.

  2. Add a mailbox

    Choose Gmail, Zoho, iCloud or another IMAP server, then sign in with an app password.

  3. Pick folders

    Choose which folders to back up and where the backup should be stored on your disk.

  4. Back up

    Start a backup and follow its progress live. You can also set a schedule and let Bmail keep your copy current.

Heads up: the installer isn't code-signed yet, so Windows SmartScreen may show a warning. Each release includes a SHA-256 checksum that you can use to verify your download.
